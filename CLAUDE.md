\# CLAUDE.md



\## Project



Notes-Web-App: a very simple browser app for writing and saving notes.



\## Read first



\- `problem.md` says who has the problem and lists the requirements

\- `spec.md` says how the app should work. Build what the spec describes.



Do not edit `problem.md`. If the spec and the code disagree, tell me before changing either.



\## Rules



\- Use plain HTML, CSS, and JavaScript only.

\- The app must run with one command: `python3 -m http.server 8000`, then open http://localhost:8000.

\- No API keys, no login, no paid services, no network calls to other sites.

\- Store notes in local browser storage. Do not add a database or a backend.

\- Keep it simple. Do not add features that are not in the spec.



\## Code style



\- Small functions with clear names. Short comments where the code is not obvious.

\- Keep the code in `index.html`, `style.css`, and `app.js`.



\## Working



\- Make a commit after every major change. After building initial project, commit. If asked to make a major change to a project, do that then commit.

\- After each change, check it in the browser against the requirements it touches.
